# NxtUp Design Principles

## Core Goal
Answer "What are we doing next?" in under 5 seconds.

## Mobile-First Focus
- Design for phone usage first.
- Prioritize thumb-friendly navigation.
- Keep key actions easy to reach.

## Speed Over Complexity
- Favor fast load times.
- Minimize steps to complete actions.
- Remove friction from adding and reviewing places.

## Quick Capture
- Add flow should complete in under 10 seconds.
- Required inputs:
  - Name
  - Category
  - Location (optional)

## Easy Decision-Making
- Default view is "Want to Visit".
- Provide clear filters:
  - Status: Want, Planned, Visited
  - Priority
  - Vibe
- Include a "Random Pick" action.

## Clean UI
- Keep layout minimal.
- Maintain clear visual hierarchy.
- Avoid clutter.

## Consistent Visual Language
- Use a limited color palette.
- Keep status indicators clear.
- Use subtle tags for vibe and priority.

## Emotion and Utility
- Product should feel personal and shared.
- Encourage real-world use, not list hoarding.
- Support memory with history and notes.

## Avoid
- Overengineering features.
- Complex navigation.
- Too many options per screen.
- Designing for edge cases early.
